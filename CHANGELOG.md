# Historial de cambios

Los cambios relevantes del proyecto se documentan en este archivo.

## [2.0.1] — 2026-07-30

### Añadido

- Nueva portada y galería responsive para el repositorio.
- Documentación profesional de arquitectura y roadmap.
- Plantillas para issues, pull requests y contribuciones.
- Pipeline de calidad con lint, TypeScript y build.
- Imagen social del proyecto y metadatos del repositorio.

### Mejorado

- Estructura editorial y navegación del README.
- Carga prioritaria del logotipo visible en el primer viewport.
- Créditos y atribución tecnológica de NovaTec.

## [2.0.0] — 2026-07-29

### Añadido

- Migración completa desde la versión PHP hacia Next.js App Router.
- Nueva identidad visual negra y cinematográfica.
- Animaciones con Motion, scroll suave con Lenis y escena Three.js.
- Contenido tipado, SEO, accesibilidad y diseño responsive.

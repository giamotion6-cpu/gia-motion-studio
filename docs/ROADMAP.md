# Roadmap de GIA Motion

El roadmap organiza el crecimiento del producto sin comprometer rendimiento ni consistencia visual.

## Ahora — Plataforma 2.0

- [x] Migración a Next.js App Router y TypeScript.
- [x] Dirección visual negra, editorial y cinematográfica.
- [x] Arquitectura por features y contenido desacoplado.
- [x] Hero con escena 3D cargada progresivamente.
- [x] Experiencia responsive y movimiento reducido.
- [x] Documentación, CI y flujo de contribución.

## Siguiente — Portafolio profundo

- [ ] Rutas individuales para casos de estudio.
- [ ] Galerías de video y fotografía por proyecto.
- [ ] Filtros por servicio, industria y tipo de producción.
- [ ] Métricas de conversión y eventos clave.
- [ ] Formulario conectado a un servicio transaccional.

## Después — Operación editorial

- [ ] CMS headless con previsualización.
- [ ] Blog de producción, técnica y tendencias.
- [ ] Biblioteca reutilizable de testimonios y clientes.
- [ ] Optimización automática del reel por dispositivo.
- [ ] Panel editorial con roles y borradores.

## Futuro — Experiencias inmersivas

- [ ] Escenas WebGL específicas para proyectos destacados.
- [ ] Recorridos 360° integrados.
- [ ] Versión en inglés.
- [ ] Personalización por campaña o industria.
- [ ] Sistema de diseño compartido para nuevas propiedades digitales.

## Criterio de priorización

Cada iniciativa se evalúa por impacto comercial, valor para la audiencia, coste de mantenimiento y efecto en Core Web Vitals.

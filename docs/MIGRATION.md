# Migración desde la versión PHP

La versión PHP fue sustituida por Next.js. Antes de retirarla se conservaron:

- El logo original en `public/images/gia-logo.png`.
- El reel original en `public/media/gia-reel.mp4`.
- La descripción de empresa, misión, servicios, valores, roles del equipo, proyectos, artículos, testimonio y textos de contacto en `src/content/legacy-catalog.ts`.

Los nombres de imágenes históricas como `portfolio-1.jpg`, `blog-1.jpg` o `team-1.jpg` se conservaron solo como referencia porque esos archivos no estaban presentes en el proyecto recibido. Los teléfonos, dirección y redes de la versión PHP eran marcadores de ejemplo y están señalados para que no se publiquen por accidente.
